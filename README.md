# O Eneagrama e as Leis do Devir

Um site educativo, visual e interativo sobre a **Lei de Três** e a **Lei de Sete**, conforme apresentadas nos ensinamentos de G. I. Gurdjieff.

O projeto explora o Eneagrama como um diagrama simbólico para compreender a interação de forças e o desenvolvimento de processos ao longo do tempo.

## ✨ Funcionalidades

- **Diagrama interativo:** explore os nove pontos do Eneagrama.
- **Visualização das leis:** alterne entre a Lei de Três, a Lei de Sete e a representação conjunta.
- **Exploração dos pontos:** selecione cada número para consultar sua interpretação.
- **Lei de Três:** conheça as forças afirmadora, negadora e reconciliadora.
- **Lei de Sete:** explore a analogia da oitava musical, seus intervalos e a sequência interna `1 → 4 → 2 → 8 → 5 → 7 → 1`.
- **Exemplos práticos:** aplicações ilustrativas ao cultivo de uma horta e ao aprendizado de uma língua.
- **Design responsivo:** interface adaptada a computadores, tablets e celulares.
- **Sem dependências externas:** funciona com HTML, CSS, JavaScript e SVG nativos.

## 🧭 Conteúdo

1. **Duas leis, duas perguntas** — introdução às leis e suas diferenças.
2. **Explore o Eneagrama** — diagrama interativo com os nove pontos.
3. **Lei de Três** — as três forças e suas interações.
4. **Lei de Sete** — desenvolvimento, oitava musical e intervalos.
5. **As duas leis em ação** — exemplo aplicado ao aprendizado de uma língua.
6. **Em síntese** — resumo conceitual e observações sobre o modelo.

## 🚀 Executar localmente

O projeto não requer instalação de dependências nem compilação.

1. Clone o repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```

2. Acesse a pasta:

   ```bash
   cd SEU-REPOSITORIO
   ```

3. Abra o arquivo `index.html` no navegador.

Opcionalmente, inicie um servidor local com Python:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## 🌐 Publicação com GitHub Pages

1. Envie `index.html` para a raiz do repositório.
2. Abra **Settings → Pages** no GitHub.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch principal, geralmente `main`, e a pasta `/(root)`.
5. Salve as configurações e aguarde a publicação.

O GitHub apresentará o endereço público do site na seção Pages.

O projeto também pode ser hospedado em serviços como Netlify ou Cloudflare Pages.

## 📚 Nota conceitual

Gurdjieff apresentou a Lei de Três e a Lei de Sete no contexto de um ensinamento espiritual e cosmológico.

Este site oferece uma introdução visual e interpretativa a essas ideias. O Eneagrama é tratado como um modelo simbólico para reflexão sobre processos, não como uma lei universal da física experimental.

Os exemplos cotidianos são aplicações didáticas, e não afirmações de que todos os processos obedecem literalmente a uma sequência fixa.
